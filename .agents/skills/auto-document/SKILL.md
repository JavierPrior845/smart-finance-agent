# Skill: Auto-Documentación y Registro de Investigación

**Contexto**: Esta skill se activa para documentar código, registrar hallazgos técnicos o actualizar la especificación del proyecto.

**Instrucciones a seguir:**

1. **Docstrings en Código**:
   - Aplicar el formato Google-style a funciones y clases públicas.
   - Especificar argumentos (`Args:`), retornos (`Returns:`) y excepciones elevadas (`Raises:`).

2. **Documentación de Arquitectura**:
   - Mantener el diagrama ASCII o Mermaid actualizado si un cambio modifica las capas o puertos.

3. **Formato Markdown Limpio**:
   - Usar enlaces con el esquema `file://` hacia los archivos relevantes.
   - Incluir bloques de código con resaltado de sintaxis correcto.
